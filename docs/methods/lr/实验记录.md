## 2026-10-24：完整 CIFAR-10/ResNet18 LR 拟合与评价

- **训练命令**：`python run.py fit-detector --config configs/experiments/baselines/lr/cifar10_lr_full.yaml`。
- **训练结果**：使用 40,000 个 fit 样本、10,000 个 selection 样本和 1 个 epoch；fit MSE 为 `0.0163320`，selection MSE 为 `0.0104146`。检测器检查点为 `checkpoints/detectors/20261024_160419_fit-detector_c083bd/detector.pt`。
- **全量 PGD**：使用与训练绑定一致的 `cifar10_lr_full.yaml`，测试集 8,000 个样本，`epsilon=8/255`、20 步标准 Linf PGD。7,663 个 clean-correct 样本全部被攻击成功；paper-protocol AUROC 为 `0.9272`，成功攻击绕过率为 `0.3809`。
- **AutoAttack 子集**：复用完整训练检查点，在 128 个测试样本上运行标准 AutoAttack（APGD、APGDT、FAB、Square）；119 个 clean-correct 样本全部被攻击成功；paper-protocol AUROC 为 `0.9012`，成功攻击绕过率为 `0.4874`。
- **解释**：这些是 CIFAR-10/ResNet18 的论文方法适配结果，不是论文 ImageNet/CIFAR-100 表格的直接重现；AutoAttack 结果使用 128 样本子集，不能替代完整测试集统计。

## 2026-10-24：统一协议下的固定层与完整攻击重训

- **协议**：固定 LR 层为 `backbone.layer1.1.conv2`、`backbone.layer2.1.conv2`、`backbone.layer3.1.conv2`；fit 40,000、selection 8,000、calibration 2,000 均来自 CIFAR-10 训练集，最终 evaluation 使用完整 CIFAR-10 测试集 10,000 张；batch size 16；PGD 与 AutoAttack 共用完全相同的 calibration/test split 和阈值。
- **训练**：5 个 epoch，selection MSE 用于选择最佳 epoch。各 epoch selection MSE 为 `0.00805468`、`0.00672090`、`0.00569978`、`0.00543335`、`0.00544411`，最终选择第 4 个 epoch。fit MSE（第 4 个 epoch）为 `0.00288043`。检查点：`checkpoints/detectors/20261024_173613_fit-detector_e3f316/detector.pt`。
- **PGD**：完整 10,000 张 test，9,571 个 clean-correct、9,571 个 successful-attack；AUROC `0.92493`；clean FPR `0.0497`；成功攻击检测率 `0.41020`；攻击绕过率 `0.58980`。
- **AutoAttack**：同一完整 10,000 张 test、同一 9,571 个 clean-correct、同一阈值；AUROC `0.87911`；clean FPR `0.0497`；成功攻击检测率 `0.30833`；攻击绕过率 `0.69167`。
- **结论**：统一样本、阈值、层配置和训练检查点后，AutoAttack 仍低于 PGD，说明差异不是此前的 128 样本或校准集不一致造成的。当前 CIFAR-10/ResNet18 适配的 AUROC 没有接近论文 ImageNet/CIFAR-100 主实验中的约 `0.98~0.99`，不能把论文数值直接迁移为本任务的预期结果；后续应继续核查 ResNet18 层切片、分类器训练协议、攻击参数和论文模型差异。

## 2026-10-24：CIFAR-100/ResNet50 复现实验进展

- **目标与协议**：按论文 ResNet50+CIFAR-100 设置，使用 `timm 1.0.30` 的 ResNet50，输入缩放到 `224x224`，ImageNet 均值/标准差；LR 使用 `conv2` 筛选后第 5、8、13 层，对应本实现的 `backbone.layer2.1.conv2`、`backbone.layer3.0.conv2`、`backbone.layer3.5.conv2`，并使用论文附录 F 的三组切片。PGD 与 AutoAttack 均计划使用完整 10,000 张测试集、同一 calibration 集和同一阈值，batch size 为 16。
- **依赖与数据**：已在 `cv_env` 安装 `timm 1.0.30`；CIFAR-100 已下载并解压，训练集 50,000、测试集 10,000。`run.py check-resources --config configs/experiments/baselines/lr/cifar100_lr_pgd.yaml` 已通过，CUDA 可用，输入梯度非零。
- **分类器**：使用本机缓存的 ImageNet ResNet50 权重初始化，在 CIFAR-100 上微调 8 轮（AdamW，学习率 `1e-4`，batch size 16，工程适配设置；论文未披露完整分类器训练配方）。最佳 selection 准确率 `0.84925`，完整测试集准确率 `0.8398`，正确样本 `8398/10000`。检查点：`checkpoints/classifiers/cifar100_timm_resnet50.pt`。
- **LR**：使用 40,000 fit、8,000 selection、2,000 calibration，5 轮训练；有效 fit 样本 39,569，selection 样本 6,794。各轮 selection MSE 为 `0.353750`、`0.327393`、`0.317916`、`0.313723`、`0.314194`，选择第 4 轮。检查点：`checkpoints/detectors/20261024_193951_fit-detector_d8ab72/detector.pt`。
- **PGD 当前状态**：已启动完整 CIFAR-100 测试集、`epsilon=8/255`、20 步标准 Linf PGD 三次。第一次和第二次均在生成完 10,000 张后因保存前 `torch.cat` 的临时内存峰值失败，未产生正式指标；第二次已改为 float16 batch 缓存但列表拼接仍造成峰值。第三次已改为预分配最终缓存张量、逐 batch 写入，运行到约 `1072/10000` 时按用户要求终止，未保存正式攻击缓存或指标。
- **精度说明**：float16 只用于解决攻击缓存的 CPU 内存占用，PGD 迭代本身仍使用 float32；缓存量化误差最多约 `0.000244`。若要求严格无损的最终结果，应进一步改为分 batch 的 float32 磁盘缓存和流式评价。当前尚未报告 CIFAR-100 的 PGD 或 AutoAttack AUROC、FPR、检出率和绕过率。
- **下次继续**：直接运行 `run.py evaluate --config configs/experiments/baselines/lr/cifar100_lr_pgd.yaml --detector-checkpoint checkpoints/detectors/20261024_193951_fit-detector_d8ab72/detector.pt`，先验证预分配缓存方案能完整保存；成功后再运行 AutoAttack 配置并复用相同 LR 检查点与校准协议。上次未保存 cache，因此 PGD 需要重新生成。
