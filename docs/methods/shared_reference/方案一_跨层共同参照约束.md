# 方案一 基于跨层共同参照约束的对抗样本检测

版本日期：2026年10月29日。文档性质：可执行研究设计，不是已经得到实验支持的方法论文。文中数值为建议的预注册实验设置和项目验收门槛，不是已有实测结果。

## 1 研究目标与范围

研究问题：一个输入虽然被分类为类别c，但它在不同深度的实际表示，能否由类别c中同一组正常参照样本、以相同组合权重共同解释？

目标是在相同正常误报率、同一主分类器和相同攻击预算下，降低“误分类且被检测器接受”的比例。追求增加两个攻击目标的协调难度，不要求证明它们绝对不能同时成立。

默认场景为图像分类、测试时小范数规避攻击。冻结主网络；不训练低层到高层、或高层到低层的回归器。不要求测试输入的真实标签、干净副本或攻击类型。分类器错误的正常图仍属于正常输入，不能从正常误报统计中删除。

初稿名称可用“基于跨层共同参照约束的对抗样本检测”。“共享参照权重”是具体机制，不等于已确认的新颖性。正式开题前还需对多视图共同表示、联合表示、稀疏表示检测与跨层轨迹工作做针对性查重。

## 2 立足点及其可证伪形式

### 2.1 正常关系

同一个正常物体在不同层呈现不同抽象，但这些表示来自同一次正常输入过程。假设参考集覆盖充分，在某个局部范围内，它们能由一小组正常实例以近似共同的关系描述。

这里不假设不同层坐标相同，不比较不同层向量的欧氏距离，也不要求浅层准确分类。只在每一层内部比较待测表示和该层正常参考表示。

### 2.2 攻击为何可能破坏关系

一部分攻击让中层仍保留原对象信息，后层却转向错误类别。它可能在各层分别接近不同的正常样本，使逐层距离正常，但跨层参照关系不一致。

若所有层必须使用同一套参考身份和组合权重，攻击者就不能仅让每一层各自“找到一些正常邻居”；它还须协调这些匹配关系。

### 2.3 三个具体猜想

| 猜想 | 可测预测 | 主要反证 |
| --- | --- | --- |
| H1 正常共同可解释性 | 正常图共同拟合误差处于较紧范围；在正常类别内，更多参考能改善误差但不至于过拟合一切 | 正常图误差巨大且高度分散；共同权重总明显劣于独立权重 |
| H2 攻击的参照脱节 | 在主模型成功误分类的攻击图中，共同拟合误差、或共同与独立拟合差距比正常图更大 | 差距只随低置信度、图像失真增加；攻击后各层仍可被同一错误类组合良好解释 |
| H3 协调约束具有实际价值 | 完全知晓检测器的联合攻击下，共同约束比独立逐层基线降低错误接受 | 普通攻击有收益，联合攻击后收益消失；收益实际只来自更强正常拒绝 |

H1不推出H2，H2也不推出H3。三个环节必须分别验证。“低层较稳定、高层变化大”只是可能产生H2的一种现象，不是默认成立的理论前提。

### 2.4 最重要的失败情形

1. 正常深层映射高度非线性，跨层共享线性权重不成立。
2. 错误类别的参考凸包很大，攻击很容易进入其共同解释区域。
3. 攻击从较早层开始就整体转向错误类，各层没有明显脱节。
4. 空间池化或降维丢掉真正的判别信息，正常与攻击都容易拟合。
5. 检测量只是原分类置信度的另一种表达。

## 3 完整推理链路

正常语义由一次输入生成多层表示 → 正常参考保存同一实例在各层的对应关系 → 分层独立匹配会丢掉这种实例对应 → 共同权重将对应关系加入约束 → 某些攻击只完成局部逐层伪装，因而共同拟合困难 → 若攻击同时优化拟合，它需同步协调多个层的错误类别支持 → 协调是否更困难由错误接受率和攻击收敛实验判断。

其中“共同权重拟合区域较小”可以从约束关系严格说明；“较小区域更难在输入扰动预算内到达”不能自动推出，需要实验验证。不能用约束数量更多替代鲁棒性证据。

## 4 符号及数据访问条件

| 符号 | 含义 |
| --- | --- |
| f，a(x) | 冻结的主分类器及其logits |
| c(x) | argmax a(x)，测试时当前预测类别 |
| h_l(x) | 选定层l的实际特征 |
| z_l(x) | 同层池化、降维和标准化后的特征 |
| R_c | 标签为c的正常参考实例集合 |
| D_l,c | 参考矩阵，每列为一个参考实例在层l的z_l |
| w | 参考权重，非负且和为1 |
| rho_l | 层权重，非负且和为1 |
| eta | 小的二次正则系数，保证拟合稳定 |

所有D_l,c的第i列必须对应同一个参考实例ID。各层不得独立聚类后把第i个中心当成同一实例。选择真实medoid或真实图像作为跨层参考身份；若用合成中心，必须额外证明其对应关系。

## 5 算法设计

### 5.1 数据划分

以CIFAR-10的50000张训练图为例：D_model=40000，D_dev=5000，D_cal=5000，另保留官方10000张测试图。

- 主分类器、表示变换、参考选择及所有可训练组件只使用D_model。
- 从D_model中划出互不重叠的D_ref和D_fit，例如各8000张。D_ref用于参考库和变换拟合，D_fit用于正常拟合诊断；二者仍可参与主分类器训练。
- D_dev用于层号、维数、参考规模、正则、候选分数和开发攻击选择。
- D_cal仅在设计冻结后确定最终阈值，不再据它选择结构。
- 测试集仅用于最终报告；攻击可使用测试真实标签作为评估输入，检测器不能读取它。

40k训练主模型的绝对准确率不能与论文中使用全部50k训练的结果直接比较。所有本地方法使用同一冻结主模型。若采用其他划分，须在生成结果前固定并保留索引。

### 5.2 同层表示处理

第一轮选择三个中后stage的输出。以ResNet为例，使用三个stage边界，记录模块完整名称及位于激活前/后的具体位置，不依赖含糊的“第几层”。

卷积图先全局平均池化；各层独立在D_ref拟合PCA，初始保留32维。若原维数不足32则保留原维数。随后以正常均值与逐维标准差标准化，对极小标准差设下限，最后按维数对平方残差取平均。

必须比较不做PCA、16/32/64维，以及保留少量空间网格的版本。PCA只做同层变换，不承担预测其他层的任务。

### 5.3 参考库

每类初始保留64个正常真实实例，可比较16、32、64、128。优先用三个已标准化层表示的拼接距离做类内medoid覆盖选择，随机参考作为对照。两个方案使用同样参考预算。

第一版固定全参考库，不在测试时做硬kNN候选筛选，以便攻击可微、流程易审计。高类别数或大参考规模的近邻加速作为后续工程扩展，其候选切换必须加入攻击评估。

### 5.4 共同拟合

定义单层损失：

$$
L_l(w;x,c)=\frac{1}{d_l}\|z_l(x)-D_{l,c}w\|_2^2+\eta\|w\|_2^2.
$$

共同目标为：

$$
E_S(x,c)=\min_{w\in\Delta}\sum_l\rho_l L_l(w;x,c),\qquad
\Delta=\{w:w_i\geq0,\sum_iw_i=1\}.
$$

初始rho_l=1/L，eta从{1e-4,1e-3,1e-2}中在D_dev选择。正则是数值稳定手段，不声称它带来稀疏性；在单纯形上加L1惩罚是常数，不能据此宣传稀疏编码。

所有层共同求w。不得从低层单独求w再重建高层，也不添加跨层预测网络。

### 5.5 独立拟合与条件差距

$$
E_F(x,c)=\sum_l\rho_l\min_{w_l\in\Delta}L_l(w_l;x,c),\qquad G(x,c)=E_S-E_F.
$$

由于共享解是独立解的受约束子集，精确求解时G>=0。正则必须像上式一样逐层以rho加权；不能在两种目标中任意改变正则总强度。

这只证明拟合目标的大小关系，不证明正常和攻击可分。若数值上G小于负容差，应检查求解器和目标实现，不能直接截断掩盖问题。

### 5.6 主版本判定

主版本仅用s(x)=E_S(x,c(x))。正常校准分数确定阈值tau，s>tau拒绝，否则返回主模型原预测。第一版使用全局阈值，避免小类别样本量带来的不稳定。

G用于验证机制；把(E_F,G)融合成检测分数、以及加入其他类别相对误差，均作为独立扩展。必须在D_dev预先确定最终版本，不能测试后挑最好分数。

分类正确不应仅由参考拟合器代替主模型判断；若另行按argmin E_S改标签，该结果属于“检测加修正”，必须分开报告。

### 5.7 求解器与计算量

目标是带单纯形约束的凸二次规划，可用投影梯度下降或可微QP。eta>0时目标具有唯一最优解。缓存参考Gram矩阵以减少重复计算。

开发阶段对50/100/200次投影迭代检查收敛；最终候选用独立高精度QP或更多迭代核验。对凸目标F，Frank-Wolfe间隙g=gradF(w)^T w-min_i gradF(w)_i给出可用的次优性上界。建议达到g/(1+abs(F))<=1e-5，或记录未达标率并用高精度重算。

梯度攻击使用固定步数展开求解器，并测试更长展开或隐式梯度。真实判定始终使用实际部署求解器。不可把梯度难通过QP作为防御优势。

具体更新可取w初始为均匀权重，梯度为2Σ_l rho_l D_l,c^T(D_l,c w-z_l)/d_l+2 eta w。步长取不大于[2 lambda_max(Σ_l rho_l D_l,c^T D_l,c/d_l+eta I)]的倒数，再将更新值投影到单纯形。单纯形投影使用排序求截断阈值的标准算法，不用逐元素截断后随意归一化替代。固定迭代次数用于batch推理，间隙检查用于离线核验和困难样本重算；正式部署若启用重算，其分支也须在评估中保留。

## 6 流程与伪代码

```text
离线:
  训练并冻结f；固定L个层和各自同层变换T_l
  选择每类真实参考实例R_c，并保存所有层的对应特征矩阵
  在D_fit验证拟合与收敛，在D_dev选择参数
  冻结配置，用D_cal的所有正常图计算E_S(x, f(x))并定tau

在线 DETECT(x):
  一次前向读取logits和各层实际表示
  c = argmax(logits)
  z_l = T_l(h_l(x))
  w = SolveSharedQP(z_l, D_l,c)
  s = SharedObjective(w)
  if s > tau: return REJECT
  else: return c
```

流程：输入 → 主模型多层实际表示 → 各层独立标准化 → 当前预测类别正常参考库 → 跨层共同求解权重 → 拟合分数 → 正常阈值 → 接受/拒绝。

## 7 可选的联合绕过训练

先做纯正常参考版本。只有它在普通与联合攻击下有基本信号，再考虑学习少量层权重或同层投影。引入攻击训练后必须明确标为监督增强版，不再称全流程无攻击训练。

增强训练针对“主模型已误分类且分数仍低”的样本增加[ tau_train + m - s(z) ]_+，同时保持正常分数低和表示非退化。投影需有维数、正交或方差保持约束，避免通过毁坏正常表示制造检测差异。训练阈值来自训练/开发数据，最终tau仍重新在D_cal校准。

还应训练使用同样攻击、同样参数预算的独立逐层基线，以分离“共同约束收益”和“额外对抗训练收益”。这不是首轮必选模块。

监督来源需进一步区分：参考矩阵可以完全由正常图建立，但若D_dev上用攻击表现选择层、正则或分数，就已经使用了攻击指导的模型选择。主表须标注这一点。额外设一个仅按正常覆盖和数值稳定选择参数的版本，才可检验完全不接触攻击的开发条件；“无攻击参数训练”不能写成“整个开发流程未见攻击”。

## 8 完全自适应攻击设计

攻击者知道主模型、层号、PCA、标准化、全部参考实例、QP、正则和阈值，可对全部操作求导。默认没有秘密参数。

对每个候选错误类t，构造目标margin损失：

$$
\ell_t(z)=[\max_{j\ne t}a_j(z)-a_t(z)+\kappa]_+.
$$

采用梯度下降最小化：

$$
\ell_t(x+\delta)+\lambda[E_S(x+\delta,t)-\tau]_+,
\quad \|\delta\|_p\leq\epsilon.
$$

这样在类别t固定时无需对argmax求导。最终仍检查真实argmax不等于y、真实分数不大于tau、范数及像素范围合法；优化目标低不等于攻击成功。

攻击清单：

1. 普通APGD/PGD/CW与标准AutoAttack：只作非联合参照，不据此宣称抵抗自适应。
2. 上述联合目标：lambda取{0.01,0.1,1,10,100}，各项尺度在开发集固定，不在测试时只挑对防御有利的权重。
3. 先误分类后降低检测分数，以及先进入接受区再增加错误类margin的交替攻击。
4. 直接匹配错误类参考轨迹的特征攻击，可初始化到某一参考实例的特征方向，检查是否存在比惩罚法更强的绕过路径。
5. 对QP梯度做有限差分检查，比较短展开、长展开和高精度前向；补充SPSA或迁移攻击排除梯度问题。

CIFAR-10在强攻击子集枚举9个目标类；大类别任务至少先攻击多个近竞争类，再随机补充目标，明确说明未穷尽。步数先100，再200/500/1000，重启先5，再20。记录每一步“真实联合成功”的最佳样本，不能只看最后一步。

每个原始输入以全部攻击配置的成功并集评估，不能平均攻击成功率。若更大预算或更多步数的记录成功率降低，优先检查最佳样本累计和实现。

## 9 实验设计

### 9.1 分阶段范围

| 阶段 | 设置 | 目的 |
| --- | --- | --- |
| P0 数值核验 | 人工小矩阵、1000张正常图 | 列身份一致、G非负、QP收敛、有限差分一致 |
| P1 机制试验 | CIFAR-10单骨干，D_dev中的1000正常及其攻击 | H1/H2是否有信号，不接触最终测试 |
| P2 联合攻击 | CIFAR-10两种骨干，预先抽取1000张测试图 | 检验H3与攻击收敛 |
| P3 扩展 | CIFAR-100或GTSRB，至少3个参考/训练随机种子 | 覆盖、类别数和跨模型稳定性 |

威胁预算建议：L_inf={2,4,8}/255，以8/255为主设置；L2作为单独扩展，不与L_inf数值混合比较。分布漂移另测轻度高斯噪声、JPEG、模糊与颜色变化，不混入攻击成功统计。

### 9.2 必要基线

- 无检测主分类器；最大概率和logit margin阈值。
- 单层原型/距离检测、逐层独立拟合E_F、DkNN。
- 原LR；能够复现时加入AFLS，清楚保留其默认变体。
- 同样多层表示直接拼接的轻量检测器；它若用攻击训练，必须标注监督条件。
- 共同参考版本，及打乱跨层参考实例ID的负对照。

所有方法使用同一主模型、相同可用参考数据和相同整体正常误报率。不能强行让原方法使用不适配配置；同时报告其原推荐配置和资源匹配设置。

### 9.3 关键消融

1. 共同权重与独立权重；同层表示和参考规模完全一致。
2. 跨层列ID保持与随机打乱。若打乱不影响结果，不能声称利用了实例对应。
3. 单层/双层/三层，删除最早或最晚层。
4. 参考规模、PCA维数、eta；观察大库是否让攻击也容易拟合。
5. 按正常置信度和分类margin分箱比较，排除只检测低置信输入。
6. 误差绝对值E_S与诊断差距G分开；不能因G本来非负就当检测成功。
7. 正常类多样性、少样本类别、自然误分类正常图单独分析。

## 10 指标与统计规则

记A(z)=1[s(z)<=tau]，原始正确集合I0={i:f(x_i)=y_i}。

- 正常误报率FPR=Pr[A(x)=0]，在所有正常测试图上报告。
- 正常覆盖率=Pr[A(x)=1]，接受后的分类错误率=Pr[f(x)!=y且A(x)=1]/Pr[A(x)=1]。
- 主攻击指标JASR0：在I0中，有至少一个预算内样本同时误分类且被接受的比例。分母对所有方法固定。
- 全体样本错误接受率：每张测试图的候选集中加入原图delta=0，再统计是否存在错误接受；包含原本分类错误的正常图。
- 攻击成功样本上的TPR及AUROC只作辅助。不同检测器不能各自挑一个有利攻击集合来比较。
- 报告额外延迟、内存、参考库大小、主网络前向次数和QP迭代数。

tau在D_cal上针对1%和5%误报率分别固定，主结论以5%为起点。5000张校准集不支持把0.1%尾部当作稳定主结论。有限样本分位数可按k=ceil((n+1)(1-alpha))的升序统计量选，k>n时取无穷阈值；其误报控制需要校准/测试交换性，不能外推到自然漂移或攻击。

跨方法差异用同一原图的配对bootstrap报告95%区间；一个原图的全部攻击归为同一统计单元。参考选择随机性至少3种子，单独列出均值、标准差和最差种子，不把攻击重启当成独立图像扩大样本量。

## 11 验收标准与停止条件

以下为建议项目门槛，应在看最终测试结果前固定；“百分点”表示绝对差。

| 关卡 | 建议通过条件 | 不通过时判断 |
| --- | --- | --- |
| A 实现正确 | G非负至数值容差；部署与核验求解结果近一致；固定随机性可重复；攻击梯度通过数值检查 | 修实现，不得讨论鲁棒性 |
| B 正常可用 | 目标5%FPR时独立测试FPR建议落在3%–7%；报告区间与类别分布，无大规模单类拒绝 | 若持续偏离，说明校准或参考覆盖失败；不能用测试集重新定tau |
| C 机制成立 | 独立逐层基线与共享版本匹配FPR后，普通攻击JASR0降低至少5个百分点；列身份打乱明显削弱收益 | 没有共同对应证据，最多称多层距离检测 |
| D 自适应有效 | 两个骨干上对最强联合攻击并集，比最强资源匹配核心基线JASR0至少降低5个百分点，配对95%区间下界>0；至少3种子方向一致 | 只有非联合收益则不能作为抵抗自适应的主章结论 |
| E 评估够强 | 步数500→1000、重启10→20后JASR0增幅均小于约1个百分点，且不同攻击族无大幅突破 | 属于尚未充分收敛的经验结果，不是安全证书 |
| F 工程可接受 | CIFAR-10单输入延迟不超过主网络约3倍作为初始目标，实测峰值内存可部署 | 超预算可改参考规模，但必须重跑完整评估 |

如果初始JASR0很低存在地板效应，5个百分点门槛不适用。应在开发阶段预先改为相对下降至少20%、区间支持正收益，并说明绝对差；不得因最终结果不理想事后切换规则。

停止主线的条件：合理的参考规模和2–3种层选择下H1持续不成立；或联合攻击使收益小于约2个百分点且不稳定；或所有优势均能被margin基线解释。负结果应保留，不通过增加大量统计量掩盖。

## 12 最小交付与论文组织

最小程序模块：feature_extractor、reference_bank、simplex_qp、shared_score、calibration、adaptive_attack、metrics。保存分割索引、模型哈希、模块层名、PCA参数、参考实例ID、求解容差、tau、攻击配置与每图最佳联合样本。

最小图表：正常/攻击的(E_F,G)散点与分箱；联合攻击误分类margin—检测分数轨迹；参考规模曲线；共同/独立/打乱列ID消融；最强攻击并集主表；误报与延迟表。

章节顺序：问题及约束 → 共同参照假设 → 算法及数值性质 → 完全自适应威胁模型 → 机制与消融 → 联合攻击结果 → 失败案例与适用边界。只可证明G非负等算法性质，不把它写成检测保证。

## 13 主要相关工作与引用边界

1. [LR](https://arxiv.org/abs/2506.20816)：跨层回归是本方案明确不采用的结构。
2. [DkNN](https://arxiv.org/abs/1803.04765)：已有多层正常邻居支持；本方案须检验共享实例组合是否增加价值。
3. [TED](https://arxiv.org/abs/2312.02673)：研究后门输入的跨层拓扑演化，任务不同，作为轨迹相关工作而非本方案有效性的依据。
4. [Random Subspace Analysis，WACV 2022](https://openaccess.thecvf.com/content/WACV2022/papers/Drenkow_Attack_Agnostic_Detection_of_Adversarial_Examples_via_Random_Subspace_Analysis_WACV_2022_paper.pdf)：说明正常原型与子空间一致性已有研究，不能把“多子空间”本身作为创新。
5. [On Adaptive Attacks to Adversarial Example Defenses](https://arxiv.org/abs/2002.08347)：用于确定联合目标、攻击多样性和真实判定核验的评估责任。
6. [Detecting Adversarial Examples Is Nearly As Hard As Classifying Them](https://proceedings.mlr.press/v162/tramer22a.html)：约束鲁棒检测主张的理论背景，不表示此方案已达到相应鲁棒性。

本方案的潜在贡献是“共享参考身份与权重的跨层约束及其联合攻击实证”，不是已经完成的新颖性证明，也不是普适攻击检测。
