# 实验记录

## 2026-10-26：独立 LR Innovation 代码实现

- **目标**：实现基于条件标准化残差和分类决策方向分数的研究版本，同时确保不影响原始 LR。
- **代码隔离**：新增 `research/r001_lr_innovation/`、独立 CIFAR-10/ResNet18 配置、`scripts/methods/lr_innovation/run_lr_innovation.py` 和 `tests/methods/lr_innovation/test_lr_innovation.py`。未修改原始 `src/advdetect/detectors/baselines/lr.py`、原有 detector factory、baseline LR 配置或现有 checkpoint。
- **实现内容**：独立 LR MLP 与特征 hook；5 折 out-of-fold clean residual 统计；MSE、centered-MSE、全局/条件对角白化、top-2 决策方向双侧/单侧分数；独立 fit/evaluate 命令和 checkpoint binding。
- **验证**：`cv_env` 下完整单元测试 13 项全部通过；新模块和脚本通过 `py_compile`；PGD 与 AutoAttack 配置继承及模块导入检查通过。没有启动完整 CIFAR-10 训练或攻击实验。
- **入口**：先运行 `python scripts/methods/lr_innovation/run_lr_innovation.py fit --config configs/experiments/proposed/lr_innovation/cifar10_lr_innovation_pgd.yaml`，再用返回的 checkpoint 运行 `evaluate`；AutoAttack 使用 `configs/experiments/proposed/lr_innovation/cifar10_lr_innovation_autoattack.yaml`。
- **状态与限制**：目前只完成代码和小型测试，尚无检测性能结论。新评价入口逐批生成攻击并立即评分，当前没有建立可断点续跑的独立 attack cache。
