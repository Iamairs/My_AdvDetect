# 实验记录

## 2026-10-25：Provable Noise Amplification/JAD 的 CIFAR-100/ResNet50 迁移实验启动

- **最终协议**：按用户确认改用 CIFAR-100 + ResNet50；训练 Default 与 Ours 两个模型，各 100 个独立随机初始化；每个模型 50 epochs、Adam、学习率 `1e-2`、batch size `16`。Default 使用 ReLU；Ours 使用 LeakyReLU(负斜率 `0.01`) 与论文公开的谱损失 `L_cls - 1e-2 * sum(log(sigma_min(W)))`。
- **检测与攻击**：JAD 使用首层 `backbone.conv1`、末层 `backbone.layer4.2`，JPEG quality `75`；标准 Linf PGD 和标准 AutoAttack 均使用完整 CIFAR-100 测试集，并使用独立 calibration 集和统一阈值协议。攻击预算沿用当前项目约定 `epsilon=8/255`，PGD 20 步、step `2/255`。
- **迁移边界**：论文原始实验为 CIFAR-10 + WideResNet；ResNet50 + CIFAR-100 是本项目的忠实迁移设置，论文没有披露该组合的完整分类器训练配方，因此最终结果将标注为迁移复现，不宣称是论文原始表格逐项复现。
- **运行状态**：先以 224×224 做了代码/显存验证；实测单 epoch 数分钟，100×2 个模型按 50 epochs 将达到数周，因此该配置不作为正式结果。正式迁移改用 CIFAR 原生 32×32 输入，ResNet50 结构、50 epochs、batch size 16 和其余协议保持不变。训练脚本新增 `--skip-complete`，可在中断后依据 checkpoint 中记录的 epoch 续跑/跳过已完成 seed。

## 2026-10-25：固定完整训练后的代表模型评价协议

- **用户确认**：继续使用 CIFAR-100 + ResNet50；不切换到 ResNet18 + CIFAR-10。先完成 Default/Ours 各 100 个独立 seed 的训练，再进行攻击评价。
- **代表模型**：预注册使用两个变体的 `seed_000.pt`，不根据攻击结果事后挑选 seed。
- **评价顺序**：训练完成后依次运行 Default-PGD、Default-AutoAttack、Ours-PGD、Ours-AutoAttack；每组均使用完整 CIFAR-100 测试集。PGD 与 AutoAttack 在同一变体内复用相同的 calibration 划分、检测器配置和阈值校准规则。
- **自动化**：`scripts/training/jad/local/run_jad_seed0_after_training.ps1` 监控两组 checkpoint 数量，只有 Default 和 Ours 均达到 100 个后才启动上述四组 `run.py run` 评价；运行日志写入 `logs/jad_seed0_evaluation.log`。

- **进度更新（2026-10-26 21:27，本机时间）**：Ours `seed=0` 已完成第 31/50 epoch，第 31 轮 train loss `2.65188`、train accuracy `0.31305`、selection accuracy `0.33213`、test accuracy `0.33910`。进程正常运行，GPU 利用率约 84%，显存约 727 MiB，错误日志为空。按约 40 分钟/epoch估算，训练剩余约 12.5–13 小时；之后 4 组完整测试集攻击评价耗时依赖 AutoAttack 实际进度，暂估约 1–3 小时，全部完成约还需 14–16 小时。
- **单 seed 影响**：节省其余两个 Ours seed 的约 2.5 天训练时间；保留一个完整 seed 的检测性能与攻击结果，但无法估算 Ours 跨初始化的均值、标准差和随机种子敏感性。Default 已训练的 3 个 seed 仍保留；主攻击比较使用同编号 seed 0，统计口径标记为单模型结果，不把 Default 的多 seed 结果与 Ours 单 seed 结果直接当成对称的显著性比较。
- **耗时原因核实**：CIFAR-100 fit 集 40,000 张、batch size 16，每 epoch 约 2,500 个 optimizer step。当前 `spectral_loss()` 在每个 step 遍历 ResNet50 的 53 个卷积层，对每个卷积权重执行一次精确 `torch.linalg.svdvals()`，并将最小奇异值的对数纳入反向传播。因此约为 132,500 次 SVD/epoch、约 6.6 million 次/seed（50 epochs），且 SVD 强制使用 float32，不能从分类损失的 autocast 中获益。每轮还要额外跑 8,000 张 selection 和 10,000 张 test 做评估。按当前约 39–40 分钟/epoch，单个 Ours seed 约 33 小时，三个 seed 预计约 4 天；这是完整谱损失实现的计算成本，不是进程停滞。
- **准确率解释（2026-10-26）**：Ours 第 31 epoch test accuracy `33.91%`，远高于 CIFAR-100 均匀随机猜测的 `1%`，说明网络已学到有效类别信息；但它仍属低准确率/明显未充分收敛的分类器表现。对照 Default seed 0：第 50 epoch test accuracy `35.62%`，按 selection accuracy 选择的 epoch 47 对应 test accuracy `36.74%`。因此 Ours 当前约低 2.8 个百分点，且需等 50 epoch 和 best-selection checkpoint 后再公平比较。对当前从随机初始化、仅 40k fit 样本、50 epoch、timm 标准 ResNet50 stem 直接处理 32×32 输入、Adam lr=0.01 的适配配置，约 35–40% 是根据 Default 实测给出的经验预期，不是论文目标或可靠保证。常见 CIFAR-100 ResNet50 高准确率结果通常采用更长训练、CIFAR 专用 stem/调度，或 ImageNet 预训练微调；不能把那些数字直接当成当前配置的验收线。若最终仍在该区间，说明本实验主要检验谱约束对当前低准确率分类器的影响，不能代表充分优化的 CIFAR-100 分类器下的 JAD 能力。
- **有效性风险更正（2026-10-26）**：核对发现项目已有的 CIFAR-100 timm ResNet50 分类器使用 ImageNet 预训练权重、224×224 输入和 8 轮微调，测试准确率为 `83.98%`；而当前 JAD Default/Ours 训练脚本重新随机初始化分类器、用 32×32 输入仅训练 50 轮，Default 最佳测试准确率只有 `36.74%`。此前把 `35–40%` 描述为“当前配置的经验预期”只是在解释已实现流程，不代表该设置适合作为论文方法的最终分类器。两套模型初始化与输入预处理不一致，当前 JAD 攻击结果不能与 83.98% 分类器条件下的论文/项目结果作直接对比；低分类准确率也会改变可攻击样本数量和检测指标。后续如要声称充分复现，应先统一并验证高准确率分类器协议，再决定 Default/Ours 是否从同一分类器权重初始化并训练谱约束变体；当前单 seed 训练结果只能标作低准确率设置下的探索性迁移结果。
